Attribution and redistribution
==============================

No software license has been selected on the researcher's behalf. Public
visibility does not grant a particular open-source license.

The public repository contains Python code, tests and documentation only.
Original measurements, MAT arrays, publisher PDFs and archived MATLAB
source are excluded. MATLAB attribution is retained unchanged locally;
third-party functions require a separate rights review before redistribution.
NumPy, SciPy, h5py, Matplotlib and pytest are installed dependencies, not
vendored. GitHub Actions are pinned to official release commits.

The SPOD kernel independently expresses correlation-filtered SPOD, not
Welch/frequency-domain SPOD. Cite Sieber, Paschereit & Oberleithner (2016),
JFM 792, 798–828, as well as the 2025 Du et al. paper. The local Sieber
MATLAB routine remains archived with its original author notices.
