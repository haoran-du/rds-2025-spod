MATLAB source archive
=====================

This paper's local archive contains 16 source/autosave files at
``archive/matlab`` with DATA-relative paths, unchanged bytes and SHA-256
checksums. The public repository contains the index, not the source files.
The original combined archive still retains all 140 files, including
unassigned explorations. No source has been deleted as obsolete.

Some scripts or plotting helpers support more than one paper. Such shared
sources can appear in more than one local archive with the same checksum.
The candidate classification is for navigation, not evidence that every
variant contributed to a published figure. Check THIRD_PARTY.rst before
redistributing MATLAB sources.
